# Task Planner

Недельный планировщик c тремя темами (светлая, тёмная, готическая) и круговыми прогресс-барами.

## Стек
- **Фронтенд:** React + Vite
- **Бэкенд:** Node.js + Express
- **База данных:** PostgreSQL
